# 部门二：档案室 (Archives)

> 文档档案规范，让知识井然有序

---

## 5分类体系

| 类别 | 特征 | 例子 | 变化频率 |
|------|------|------|---------| 
| **机制/** | 框架级操作流程 | 铁律/记忆规范 | 几乎不变 |
| **方案/** | 管理设计方案 | SOP/成本/模型选型 | 按需更新 |
| **项目/** | 对外产出 | 报告/安装包 | 项目周期 |
| **会议/** | 会议纪要 | 开发纪要/汇总 | 即写即走 |
| **档案/** | 已完结交付物 | 项目归档 | 自动生成 |

**核心分界线**：机制=框架规则，方案=当前设计，项目=给用户的产出

---

## 目录结构（子分类体系）

```
档案室根目录（ARCHIVES_DIR 可配置，默认 ~/.hermes/archives）
├── INDEX.md                     # ★ 自动生成（archive-index.py），勿手改
├── 机制/                        # 制度类
│   ├── 铁律/                    # 审批/双门槛/归档铁律
│   └── 记忆/                    # L1/L2/L3/下沉机制
├── 方案/                        # 设计类
│   ├── 成本/                    # 模型成本/账单分析
│   ├── SOP/                     # SOP-00~08
│   ├── 模型/                    # 模型选型/API文档
│   └── 架构/                    # 体系设计
├── 项目/                        # 交付物
│   ├── 报告/                    # 对外报告（pdf/docx/md）
│   ├── 安装包/                  # zip/发布包
│   └── 版本/                    # 版本发布记录
├── 会议/                        # 纪要
│   └── <年份>/                  # 按年分
├── 档案/                        # 完结归档
│   └── <年份>/                  # 按年分
```

**子分类扩展规则**：文件 >10 个时自动拆分子类；分类名称见上。

---

## 命名规范（强制）

```
格式：[日期]-[分类]-[主题]-[版本].ext
示例：
  20260815-方案-模型成本对比-v1.md
  20260815-会议-开发纪要-v1.md
  20260815-项目-长春服装报告-v1.pdf
规则：
  日期 YYYYMMDD 开头（可排序）
  主题简洁明确
  版本号结尾（可回溯）
```

---

## 强制规则

1. root 只允许 INDEX.md + 分类文件夹
2. 每个 .md 文件必须含 YAML frontmatter
3. **INDEX.md 由 archive-index.py 自动生成，禁止手改**（写完文件运行一次脚本）
4. status=archived 移入 档案/<年份>/
5. 项目完结时清理项目段
6. 文件 >10 个/分类时拆分子分类

---

## 索引自动生成

```bash
# 档案室新增/修改文件后，重新生成 INDEX.md
python3 scripts/archive-index.py [档案室路径]
# 默认路径：ARCHIVES_DIR 或 /media/kellen/DATE/hermes 或 ~/.hermes/archives
```

---

## 生命周期管理

```
新建文件 → 对应分类+子分类 → 命名合规 → 运行 archive-index.py
项目完结 → 移入 档案/<年份>/
年度归档 → 打包压缩（tar.gz → 档案/年度包）
清理策略 → 会议/保留2年，档案/长期
```

---
