## 脚本说明

### worker-ant-dispatch.sh (阶段1)
智能任务路由器，自动分析任务类型并分配给合适的Agent。

```bash
# 基本用法
worker-ant-dispatch '帮我设计一个登录页面'
worker-ant-dispatch '修复登录Bug'
```

### worker-ant-queue.sh (阶段2)
任务队列管理，基于Hermes Kanban的任务队列系统。

```bash
# 添加任务到队列
worker-ant-queue add '设计登录页面'

# 指定Agent
worker-ant-queue add --agent coder '修复登录Bug'

# 指定优先级 (1=紧急 2=重要 3=普通)
worker-ant-queue add --priority 1 '线上崩溃紧急修复'

# 目标循环模式
worker-ant-queue add --goal '完成用户系统重构'

# 执行队列中的下一个任务
worker-ant-queue run

# 查看队列状态
worker-ant-queue status

# 进度看板
worker-ant-queue dashboard
```

### worker-ant-dashboard.sh
独立的进度看板脚本。

```bash
worker-ant-dashboard
```

### worker-ant-v3.sh (阶段3)
依赖图、结果汇总、负载均衡。

```bash
# 创建任务依赖
worker-ant-v3 link t_abc123 t_def456

# 查看任务依赖
worker-ant-v3 deps t_def456

# 查看Agent负载
worker-ant-v3 load

# 推荐执行Agent
worker-ant-v3 recommend '开发登录API'
```

## 超时应对

### 三级升级机制

| 级别 | 条件 | 动作 |
|------|------|------|
| L1 | 正常时间内完成 | 正常接收 |
| L2 | L1超时 | 预读关键数据 → 传给新Agent |
| L3 | L2超时 | 诊断日志 → 修复 → 重调度 |

### 配置参数

```yaml
delegation:
  child_timeout_seconds: 1800
  max_iterations: 50
  max_concurrent_children: 3
  max_spawn_depth: 1
```

## 故障排除

### 问题1: worker-ant-queue command not found

**原因**: 脚本未安装到PATH中

**解决方案**:
```bash
# 检查脚本位置
ls ~/.hermes/scripts/worker-ant-*.sh

# 如果存在，添加到PATH
export PATH="$HOME/.hermes/scripts:$PATH"

# 或创建符号链接
sudo ln -s ~/.hermes/scripts/worker-ant-queue.sh /usr/local/bin/
```

### 问题2: hermes kanban command not found

**原因**: Hermes版本不支持kanban命令

**解决方案**:
```bash
# 检查Hermes版本
hermes --version

# 如果版本过低，升级Hermes
pip install -U hermes-agent
```

### 问题3: 任务创建失败

**原因**: Agent profile不存在

**解决方案**:
```bash
# 检查可用的profiles
ls ~/.hermes/profiles/

# 确认Agent profile名称
# 正确格式: mibao-kills-pm, mibao-kellen-coder 等
```

### 问题4: 任务队列为空但有任务

**原因**: 任务状态不是ready

**解决方案**:
```bash
# 查看所有任务状态
hermes kanban list

# 如果任务在其他状态，可能需要claim
hermes kanban claim <task_id>
```

### 问题5: Agent匹配不准确

**原因**: 关键词匹配规则需要调整

**解决方案**:
```bash
# 查看当前匹配逻辑
cat ~/.hermes/scripts/worker-ant-queue.sh | grep -A 20 "match_agent"

# 如需自定义，修改脚本中的关键词列表
```

### 问题6: 脚本执行报错 "permission denied"

**原因**: 脚本没有执行权限

**解决方案**:
```bash
chmod +x ~/.hermes/scripts/worker-ant-*.sh
```

## 使用示例

### 示例1: 设计新功能
```bash
# 自动匹配PM
worker-ant-dispatch '设计一个用户登录页面，包含邮箱和手机号两种方式'

worker-ant-queue add --priority 1 --agent coder '线上支付回调失败，紧急修复'

### 示例3: 批量任务处理

worker-ant-queue run
```

### 示例4: 查看进度
```bash
# 进度看板
worker-ant-queue dashboard
```
